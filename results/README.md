# Legacy baseline artifacts

The files in this directory were generated by the pre-repair pipeline. Their aggregate values
are internally consistent, but the original checkpoint, dataset fingerprint, split manifest,
full history, and exact environment were not published. They must not be represented as output
from the repaired version-2 code.

Run `train.py` and `test.py` again to create provenance-bound results containing instance-level
metrics, confidence intervals, validation threshold search, independent counting baselines,
and checkpoint hashes.
